# Brightlayer Distributed IT - Lite 3.1.0 - Release note
(Oct 2026)

## Packaging:

The release is delivered in the following formats:

* OVA package for VMware workstation 25 or VMware 7.0 (U3) or higher
* OVA package for VirtualBox 7.2.x
* EXE package for Hyper-V versions 2025, 2022, 2019
* OVA package for Proxmox versions 9.1.x, 8.4.x
* Upgrade package for DIT-Lite 3.0.0

## Virtualization Connectors:

### Microsoft: New Hyper-V Failover Cluster Connector

Microsoft Hyper-V Failover Clusters can now be discovered and monitored without SCVMM,
by connecting to any node of the cluster. The cluster, its nodes and its virtual
machines are discovered automatically.

Note: WinRM and OpenSSH must be enabled and configured on each Windows server.

This connector provides HCI Cluster Shutdown and Restart action that safely orchestrates
the shutdown of the virtual machines and of the hosts, and hands the final shutdown steps
over to the Eaton UPS Network Management Card where applicable.

### Microsoft: New cluster action for SCVMM Connector

* HCI Cluster Shutdown and Restart

HCI clusters managed through SCVMM can now be gracefully shut down and automatically restarted through the new SCVMM
action HCI Cluster Shutdown and Restart, whether DIT-Lite is deployed inside or outside the cluster,
using an eligible Eaton UPS card.

The restart procedure restores the cluster and the infrastructure according to the state and the options
selected before the shutdown.

Prerequisites: WinRM and OpenSSH (for cluster actions) must be enabled and configured on each Windows server.

Recommendation: Install Integration services on each Virtual Machine (VM) to enable VM IP address monitoring required
to perform VM graceful shutdown.

### VxRail: New cluster action for VxRail Manager Connector

* HCI Cluster Shutdown and Restart

#### Cluster actions details

* Cluster actions are compatible with STANDARD Clusters (and STRETCHED Clusters with a known limitation described hereafter)
* HCI Cluster Shutdown and Restart features require an Eaton Network M3 Card (version 2.2 or higher), except when Brightlayer Disaster Avoidance Add-on is deployed outside the target cluster.
* Cluster returns to its previous state after shutdown and restart.
* User virtual machines restart is manageable through a provided option.

#### Supported scenario (VxRail Stretched Clusters)

* Simultaneous power failure on both sites is supported and Results in a full cluster shutdown and subsequent restart.
* Power failure on one site is supported and leads to shutdown of the affected site. Once power is restored, the same site can be restarted successfully

#### Known Limitation (VxRail Stretched Clusters)

* In a stretched cluster configuration, a power failure affecting one site followed by a power failure on the second site is not supported for automated shutdown and restart operations. This is a known VxRail limitation confirmed by Dell. As a workaround, a manual VMware vSAN shutdown procedure can be performed.

## Improvements:

* Brightlayer Distributed IT – Lite (DIT-Lite) renaming of the application finalized.
* Improved user experience on the login page.
* The settings page navigation has been improved for better user experience, and they can now be accessed directly from the left navigation menu.
* The Syslog configuration page is now available under Settings > Network in the left navigation menu.
* The HTTPS CA Certificate configuration page is now available under Settings > Network in the left navigation menu.
* The Voltage Alarm Settings template is now available through the Installation Wizard and under Settings > Alarms > Settings for USA, Europe, Europe 208V, and Australia UPS models.

## Fixes:

* Improved restoration of the VMware cluster High Availability (HA) state after a cluster restart.
* Fixed an infinite loading spinner issue when editing Automation settings.
* Fixed the issue where DIT-Lite VM is factory reset again on every reboot after a Factory Reset operation.
* Fixed the access to Mass Management credential from the Assets page.

## Cybersecurity:

* Latest package updates and security patches
